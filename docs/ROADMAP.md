# Roadmap

This file tracks features that are **not yet built**. Nothing listed here is
described as complete in the README.

## Planned

- Deploy contract to Testnet and publish contract address in docs.
- Add Albedo and xBull wallet support (requires `stellar-wallets-kit` to be
  resolvable in the build environment).
- Multi-token selector in the sender UI.
- Push notifications (e.g. via Stellar stream) when delivery status changes.
- Automatic ledger-to-date conversion in the status page expiry display.
- CLI helper script for creating and inspecting deliveries without the UI.
- End-to-end integration tests against a local Stellar quickstart node.
- Audit by an independent security researcher before Mainnet deployment.
